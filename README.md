# LayoutConverter

Simple Windows tray utility to fix text typed in the wrong keyboard layout.

## Features
- Convert selected text (EN ↔ RU)
- Global hotkey: Alt + Q
- Runs in system tray
- Enable / disable toggle
- Autostart support

## Usage
1. Run the app
2. Select text
3. Press Alt + Q

## Example
ghbdtn → привет  
руддщ → hello

## Tech
- C#
- WinForms
- WinAPI (RegisterHotKey)
